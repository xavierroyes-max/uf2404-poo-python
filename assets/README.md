# Assets de la interfaz web

Este directorio contiene los archivos de presentación e interacción del laboratorio.

## `styles.css`

Define la apariencia visual de la aplicación.

No contiene lógica de los ejercicios.

## `app.js`

Gestiona la interacción con `server.py`:

- carga ejercicios;
- genera formularios;
- ejecuta escenarios;
- muestra explicaciones;
- carga y guarda código Python;
- ejecuta y restaura archivos.

La lógica POO evaluada permanece en `../ejercicios/`.
