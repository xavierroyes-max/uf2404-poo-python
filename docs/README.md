# Documentación del proyecto

### [INSTALACION.md](INSTALACION.md)
Preparación del equipo, estructura recomendada en Windows, arranque del servidor y resolución de problemas básicos.

### [CRITERIOS_EVALUACION.md](CRITERIOS_EVALUACION.md)
Resume los criterios y reglas de evaluación indicados en la prueba y cómo se reflejan en este proyecto.

Guía completa para inicializar Git, configurar la identidad, realizar el primer commit, crear el repositorio remoto y subirlo a GitHub.
