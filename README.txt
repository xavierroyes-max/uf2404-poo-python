UF2404 - LABORATORIO INTERACTIVO DE LOS 10 EJERCICIOS
======================================================

INSTALACION
1. Descomprime la carpeta "curso_python_interactivo" dentro de C:\curso_python\
   Quedaria, por ejemplo:
   C:\curso_python\curso_python_interactivo\
2. Haz doble clic en iniciar.bat.
3. Se abrira el navegador en:
   http://127.0.0.1:8765

NO NECESITA FLASK NI INSTALAR LIBRERIAS.
Utiliza solamente Python y la biblioteca estandar.

QUE PERMITE HACER
- Elegir cualquiera de los 10 ejercicios.
- Cambiar variables desde formularios.
- Ejecutar un escenario paso a paso.
- Ver el resultado y la explicacion de cada paso.
- Ver una explicacion para alumno y otra para la defensa ante el profesor.
- Editar el codigo Python real desde el navegador.
- Guardar cambios.
- Ejecutar el .py actual con Python real.
- Restaurar la primera copia .bak creada al guardar.

SEGURIDAD
El servidor solo escucha en 127.0.0.1, por lo que no se publica en la red.
La ejecucion de los .py se limita a 5 segundos.

CIERRE
Cierra la ventana negra o pulsa Ctrl+C en ella.
